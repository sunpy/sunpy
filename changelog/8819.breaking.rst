`~sunpy.map.GenericMap.wcs` now keeps the units of the map's metadata (usually arcseconds) instead of converting to degrees.
Raw world values, such as ``map.wcs.wcs.cdelt`` or values passed to plots made with ``WCSAxes`` when using ``ax.get_transform('world')``, are now in those units, when before they would have been degrees.
To plot world coordinates, pass a `~astropy.coordinates.SkyCoord` to ``ax.plot_coord``, which handles the units for you, or pass quantities and use astropy >= 8.1.
