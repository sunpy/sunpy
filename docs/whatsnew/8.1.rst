New Fido clients for Hinode SOT data
====================================

There are now two new Fido clients for searching the Hinode Solar Optical Telescope (SOT) data hosted by the `DARTS archive <https://darts.isas.jaxa.jp/en>`__.
`~sunpy.net.dataretriever.HinodeSOTFGClient` provides the Filtergraph (FG) data at levels 0 and 1, and `~sunpy.net.dataretriever.HinodeSOTSPClient` provides the Spectro-Polarimeter (SP) data at levels 0, 1, 2 and 2.1.
The client is chosen with ``a.Detector.fg`` or ``a.Detector.sp``, and adding ``a.Provider.darts`` leaves out VSO results.

.. code-block:: python

    >>> from sunpy.net import Fido, attrs as a
    >>> results = Fido.search(a.Time("2011-12-13 06:04:30", "2011-12-13 06:04:40"), a.Instrument.sot,
    ...                       a.Level(1), a.Detector.fg, a.Provider.darts)  # doctest: +REMOTE_DATA
